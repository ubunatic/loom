2. **Popover Navigation & Focus Semantics**:
   - In `richtextedit.go`, when text is selected and the popover appears:
     - The popover is initially **unfocused** (`popoverFocusSet == false`).
     - While unfocused, if `arrows_cancel_unfocused_menu == true`, pressing arrow keys (left, right, up, down) suppresses/dismisses the popover and passes the arrow key to editor cursor navigation.
     - Pressing `menu_focus_key` (default `<tab>`) or clicking a multi-stage item (FG/BG palette, Box) transfers focus to the popover (`popoverFocusSet = true`).
     - Once focused, Left/Right (and cycling if enabled) navigate the popover buttons, and `<esc>` cancels back one level or dismisses the popover.
     - When an action is applied, if `action_closes_menu == true`, dismiss the popover; if `unselect_after_action == true`, clear the selection.
     - If the popover is cancelled / dismissed (via arrow or Esc), if `unselect_on_cancel == true`, clear the selection; otherwise keep selection intact.
     - While text remains selected and the popover is dismissed/suppressed, pressing `popup_open_key` (default `^<space>`) reopens/unsuppresses the popover.
   - Respect other specced flags (`auto_popup_on_selection`, `cycle_navigation`, `dismiss_on_scroll`, `position_preference`, `mouse_hover_focus`).
