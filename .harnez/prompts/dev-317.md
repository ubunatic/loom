## Acceptance Criteria
1. **Directional Arrow Focus**:
   - In `RichTextEdit`, when the popover toolbar appears for selected text (or `^<space>`) in an unfocused state:
     - Check whether the popover toolbar is positioned **above** or **below** the cursor/selection anchor (e.g. from `popoverGeometry`: `bar.Y < anchorY` or pointer glyph).
     - If the popover is **above**, pressing **`Up`** transfers keyboard focus to the popover (`popoverFocusSet = true`). Pressing `down`, `left`, or `right` cancels the unfocused popover and moves the editor cursor.
     - If the popover is **below**, pressing **`Down`** transfers keyboard focus to the popover (`popoverFocusSet = true`). Pressing `up`, `left`, or `right` cancels the unfocused popover and moves the editor cursor.
     - Once focused, Left/Right (and cycling) navigate items as before, and `<esc>` cancels back or dismisses.

       `e.toggleAttribute(func(s *Style, on bool) { s.Italic = on }, func(s Style) bool { return s.Italic })`
     - When `e.HasSelection` is false, `tab` does not toggle italics.
   - In `cmd/loom/edit.go`:
     - When `v.edit.HasSelection` is true, `tab` is handled by the editor (toggling italics) instead of switching panels.
     - When `v.edit.HasSelection` is false, `tab` continues switching between editor, files, and search panels when panels are open.
